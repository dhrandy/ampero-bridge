Ampero Mini model library beta

Every model on the Hotone Ampero Mini (firmware V2.2) with the code the pedal stores for it, and what it is based on. Unofficial, made from the pedal's editor and live reads.

models.jsonSource on GitHub

How to read this
Screen
position in the editor's list for that block, starting at 1.
Code
the number stored in the preset record for the model. FX1, FX2 and FX3 use different codes even for the same name.
pedal-proven
code set on a real pedal and read back from the record.
scroll-derived
FX2 codes seen while scrolling the list; not read back.
list order
code follows from the list order and a rule that held where it was checked. Not checked itself.
code unknown
name known from the editor, code not read yet.
firmware-added
in the editor's list, not in the manufacturer's effect list.
Beta. Not affiliated with or endorsed by Hotone. Product and brand names belong to their owners and appear only to say which real-world gear a model is based on. Codes marked list order or code unknown can be wrong, so read a record back before relying on one. MIT licensed, copyright dhrandy.
