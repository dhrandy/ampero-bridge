How to read this
Screen
position in the editor's list for that block, starting at 1.
Code
the number stored in the preset record for the model. FX1, FX2 and FX3 use different codes even for the same name.
pedal-proven
code read from the record on a real pedal with that model selected.
inferred
sits between two codes that were read, in an unbroken run of the list; not read itself.
Codes without a tag
follow from the list order and a rule that held everywhere it was checked (FX2 codes come from scrolling the list). Treat them as likely, and read a record back before relying on one. Only the green pedal-proven tag means a read-back on a real pedal.
Dash
the code has not been read yet.
firmware-added
in the editor's list, not in the manufacturer's effect list.
Details
short notes in our own words about the real-world gear. General background, not measurements.
